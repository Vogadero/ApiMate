# 集合

集合允许你组织、保存和运行一组相关的 API 请求。

## 集合管理

![包含文件夹和请求的集合树](/collections.png)

### 创建集合

1. 在侧边栏点击 **New Collection**
2. 输入集合名称
3. 开始添加请求和文件夹

### 使用文件夹组织

- **多层嵌套**：在文件夹中创建子文件夹进行深度组织
  - 集合 > 文件夹 > 子文件夹 > 请求
- **创建文件夹**：右键点击集合或文件夹 > New Folder
- **重命名文件夹**：右键点击文件夹 > Rename
- **删除文件夹**：右键点击文件夹 > Delete（删除所有内容）
- **复制文件夹**：右键点击文件夹 > Copy（在同一层级创建副本）

### 管理集合中的请求

- **保存到集合**：在请求编辑器中点击保存按钮，将当前请求保存到集合
- **拖放排序**：通过拖拽重新排列请求和文件夹
- **复制请求**：右键点击请求 > Duplicate
- **重命名请求**：右键点击请求 > Rename
- **删除请求**：右键点击请求 > Delete

### 集合树结构

侧边栏以层级树形结构显示集合：

```
Collection Name
  Folder
    Request 1
    Request 2
    Sub-folder
      Request 3
  Request 4
```

- **视觉层级**：不同缩进级别带有连接线
- **背景颜色**：不同嵌套级别使用交替颜色
- **上下文菜单**：右键点击任何项目可查看可用操作
- **悬停操作**：悬停时显示快捷操作按钮

### 导出集合

- 右键点击集合 > Export Collection
- 导出为 JSON 文件
- 包含所有请求、文件夹及其配置
- 可由其他 ApiMate 用户导入

## 集合运行器

集合运行器允许你自动执行集合中的所有请求。

### 运行集合

1. 右键点击集合 > Run Collection
2. 配置运行设置：
   - **运行模式**：顺序或并行
   - **最大并行请求数**：控制并发数（默认：5）
   - **迭代次数**：集合运行的次数
   - **迭代数据**：用于数据驱动测试的 CSV 或 JSON 文件
3. 点击 **Start Run**

### 迭代数据

使用数据文件进行数据驱动测试：

**CSV 格式：**
```csv
username,password,expected_status
admin,admin123,200
user,user123,200
guest,guest123,401
```

**JSON 格式：**
```json
[
  { "username": "admin", "password": "admin123", "expected_status": 200 },
  { "username": "user", "password": "user123", "expected_status": 200 },
  { "username": "guest", "password": "guest123", "expected_status": 401 }
]
```

在脚本中通过 `pm.iterationData.get("key")` 访问迭代数据。

### 运行结果

- 每个请求显示其结果：**Pass**（绿色）或 **Fail**（红色）
- 每个请求显示响应状态码和耗时
- 每个请求显示测试断言结果
- 总体摘要：总请求数、通过数、失败数、总耗时

### 前置脚本和后置脚本

集合中的每个请求都可以有在请求前后运行的脚本：

- **前置脚本**：在发送请求前修改请求（设置变量、修改请求头等）
- **后置脚本**：在收到响应后处理响应（提取数据、运行断言等）

详见[脚本与测试](/zh/features/scripts-testing)获取详细的脚本文档。
