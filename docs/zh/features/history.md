# 历史记录

ApiMate 会自动保存您的请求历史，方便快速访问和重新执行。

## 请求历史

### 自动保存

- 每次发送的请求都会自动保存到历史记录（当 `apimate.autoSave` 启用时）
- 历史条目包含：方法、URL、状态码、响应时间和时间戳
- 历史记录上限可通过 `apimate.historyLimit` 配置（默认：100）

### 固定重要请求

- **固定**重要请求，使其始终显示在历史列表顶部
- 当历史记录达到上限时，固定的请求不会被自动移除
- 点击固定图标可固定/取消固定请求

### 搜索与过滤

- **搜索**：按 URL、方法或状态码过滤历史记录
- **方法过滤**：仅显示特定的 HTTP 方法（GET、POST 等）
- **状态过滤**：仅显示特定的状态码范围（2xx、4xx、5xx）

### 从历史记录重新发送

- 点击任意历史条目可在编辑器中打开该请求
- 请求将完整恢复，包括所有请求头、请求体和认证信息
- 点击 **Send** 重新执行请求

### 清除历史

- 使用命令面板：ApiMate: Clear History
- 或点击历史标签页中的 **Clear** 按钮
- 此操作将删除所有历史条目（包括已固定的条目）

### 历史条目详情

每个历史条目显示：

| 字段 | 说明 |
|------|------|
| Method | HTTP 方法，带颜色标识 |
| URL | 请求 URL（过长时截断显示） |
| Status | 响应状态码，带颜色标识 |
| Time | 响应时间（毫秒） |
| Date | 请求发送时间 |
| Pin | 固定状态标识 |
