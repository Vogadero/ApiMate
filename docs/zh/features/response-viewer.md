# 响应查看器

发送请求后，响应查看器会以丰富的可视化方式显示完整的服务器响应。

## 响应显示

![包含响应体、响应头和状态码的完整响应查看器](/response-viewer.png)

### 响应体

响应体根据 Content-Type 进行语法高亮显示：

| 内容类型 | 高亮方式 |
|-------------|-------------|
| application/json | JSON 语法高亮，支持可折叠节点 |
| application/xml | XML 语法高亮 |
| text/html | HTML 语法高亮 |
| text/css | CSS 语法高亮 |
| 其他 | 纯文本显示 |

#### 格式化 / 原始切换

- **Pretty**：带语法高亮的格式化和缩进响应
- **Raw**：原始未格式化的响应文本
- 通过 Pretty/Raw 按钮在模式之间切换

### 响应头

所有响应头以键值对形式显示：

- 所有响应头以键值对形式显示
- 常用请求头高亮显示以便快速识别
- 点击可复制单个请求头的值

### 状态码

HTTP 状态码带有颜色指示器显示：

| 颜色 | 状态范围 | 含义 |
|-------|-------------|---------|
| 绿色 | 2xx | 成功 |
| 黄色 | 3xx | 重定向 |
| 橙色 | 4xx | 客户端错误 |
| 红色 | 5xx | 服务器错误 |

### 响应时间

- 以毫秒（ms）为单位显示
- 颜色编码：绿色表示快速，黄色表示中等，红色表示慢速响应
- 帮助识别性能瓶颈

### 响应大小

- 以人类可读格式显示（B、KB、MB）
- 包含请求头和响应体大小
- 用于监控负载大小

### Cookie 查看器

- 查看响应设置的所有 Cookie（`Set-Cookie` 请求头）
- 显示 Cookie 属性：name、value、domain、path、expires、httpOnly、secure
- 通过 Cookie 管理器命令或侧边栏访问

## 响应操作

### 复制响应体

- 一键复制整个响应体到剪贴板
- 在 Pretty 模式下保留格式

### 保存响应到文件

- 将响应体保存到本地文件
- 文件对话框选择保存位置
- 保留原始编码

### 导出为 cURL 命令

- 生成可复现请求的 cURL 命令
- 包含方法、URL、请求头和请求体
- 复制到剪贴板以便在终端中使用

### 格式化 / 原始切换

- 在格式化和原始响应显示之间切换
- 适用于 JSON 和 XML 内容类型
