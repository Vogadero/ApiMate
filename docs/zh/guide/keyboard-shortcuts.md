# 键盘快捷键

ApiMate 为常用操作提供了便捷的键盘快捷键。

## 全局快捷键

| 快捷键 | Windows / Linux | macOS | 操作 |
|--------|----------------|-------|------|
| 新建请求 | `Ctrl+Alt+N` | `Cmd+Alt+N` | 创建新的请求标签页 |
| 发送请求 | `Ctrl+Alt+S` | `Cmd+Alt+S` | 发送当前请求 |
| 切换环境 | `Ctrl+Alt+E` | `Cmd+Alt+E` | 打开环境切换器 |

## 命令面板

通过命令面板（`Ctrl+Shift+P` / `Cmd+Shift+P`）访问更多命令：

| 命令 | 说明 |
|------|------|
| ApiMate: New Request | 创建新请求 |
| ApiMate: New Collection | 创建新集合 |
| ApiMate: New Folder | 创建新文件夹 |
| ApiMate: Import Collection | 从文件导入集合 |
| ApiMate: Export Collection | 导出当前集合 |
| ApiMate: Import cURL | 导入 cURL 命令 |
| ApiMate: Import from OpenAPI/Swagger | 从 OpenAPI 规范导入 |
| ApiMate: Import from HAR | 从 HTTP Archive 文件导入 |
| ApiMate: Switch Environment | 切换当前环境 |
| ApiMate: Manage Environments | 打开环境管理 |
| ApiMate: New Environment | 创建新环境 |
| ApiMate: Run Collection | 运行集合 |
| ApiMate: Clear History | 清除所有请求历史 |
| ApiMate: Cookie Manager | 查看和管理 Cookie |
| ApiMate: Clear Cookies | 清除所有已存储的 Cookie |
| ApiMate: Refresh Data | 从存储中重新加载数据 |
| ApiMate: Keyboard Shortcuts | 显示快捷键帮助 |
| ApiMate: Settings | 打开 ApiMate 设置 |
| ApiMate: View Logs | 打开日志输出通道 |
| ApiMate: Clear Cache | 清除缓存数据 |

## 右键菜单操作

在侧边栏中右键点击项目可访问上下文相关操作：

### 集合右键菜单
- 重命名集合
- 删除集合
- 新建文件夹
- 新建请求
- 运行集合
- 导出集合

### 文件夹右键菜单
- 重命名文件夹
- 删除文件夹
- 新建文件夹（子文件夹）
- 新建请求
- 复制文件夹

### 请求右键菜单
- 打开请求
- 重命名请求
- 复制请求
- 删除请求
- 导出为 cURL

### 环境右键菜单
- 激活环境
- 重命名环境
- 复制环境
- 删除环境
- 复制环境 ID
