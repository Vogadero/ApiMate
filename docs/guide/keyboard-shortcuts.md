# Keyboard Shortcuts

ApiMate provides convenient keyboard shortcuts for common actions.

## Global Shortcuts

| Shortcut | Windows / Linux | macOS | Action |
|----------|----------------|-------|--------|
| New Request | `Ctrl+Alt+N` | `Cmd+Alt+N` | Create a new request tab |
| Send Request | `Ctrl+Alt+S` | `Cmd+Alt+S` | Send the current request |
| Switch Environment | `Ctrl+Alt+E` | `Cmd+Alt+E` | Open environment switcher |

## Command Palette

Access additional commands via the Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`):

| Command | Description |
|---------|-------------|
| ApiMate: New Request | Create a new request |
| ApiMate: New Collection | Create a new collection |
| ApiMate: New Folder | Create a new folder |
| ApiMate: Import Collection | Import a collection from file |
| ApiMate: Export Collection | Export the current collection |
| ApiMate: Import cURL | Import a cURL command |
| ApiMate: Import from OpenAPI/Swagger | Import from an OpenAPI specification |
| ApiMate: Import from HAR | Import from an HTTP Archive file |
| ApiMate: Switch Environment | Switch the active environment |
| ApiMate: Manage Environments | Open environment management |
| ApiMate: New Environment | Create a new environment |
| ApiMate: Run Collection | Run a collection |
| ApiMate: Clear History | Clear all request history |
| ApiMate: Cookie Manager | View and manage cookies |
| ApiMate: Clear Cookies | Clear all stored cookies |
| ApiMate: Refresh Data | Reload data from storage |
| ApiMate: Keyboard Shortcuts | Show shortcuts help |
| ApiMate: Settings | Open ApiMate settings |
| ApiMate: View Logs | Open the output channel for logs |
| ApiMate: Clear Cache | Clear cached data |

## Context Menu Actions

Right-click on items in the sidebar to access context-specific actions:

### Collection Context Menu
- Rename Collection
- Delete Collection
- New Folder
- New Request
- Run Collection
- Export Collection

### Folder Context Menu
- Rename Folder
- Delete Folder
- New Folder (sub-folder)
- New Request
- Copy Folder

### Request Context Menu
- Open Request
- Rename Request
- Duplicate Request
- Delete Request
- Export as cURL

### Environment Context Menu
- Activate Environment
- Rename Environment
- Duplicate Environment
- Delete Environment
- Copy Environment ID
